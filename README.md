## kmp-unit-test

Skill diseñada para crear Unit Test para proyecto KMP.
**Use:**
@kmp-unit-test **Class_Name**
Generate unit tests for this class.
If the pre-flight detects missing test dependencies,
add only the required dependencies to the project and continue.
Do not upgrade unrelated dependencies.
